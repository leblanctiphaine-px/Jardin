Projet : Base de données et liste de tâches pour le jardin de la coloc
=======================================================================

Ce projet a pour but de créer une base de données accompagnée d'une liste
de tâches (to-do list) dédiée à la gestion du jardin de la colocation.

Objectifs :
-----------
- Recenser les plantes, légumes, herbes et fleurs présents dans le jardin
- Organiser les tâches d'entretien (arrosage, taille, semis, récolte, etc.)
- Suivre l'évolution du jardin au fil des saisons
- Faciliter la coordination entre les colocataires pour les tâches à effectuer

Contenu prévu :
---------------
- Une base de données listant les végétaux du jardin (nom, date de plantation,
  besoins en eau, ensoleillement, etc.)
- Une to-do list des actions à réaliser, avec priorités et échéances
- Un suivi des tâches accomplies

En cours de développement.
